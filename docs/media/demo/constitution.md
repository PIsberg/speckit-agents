# greet Constitution

## Core Principles

### I. Test first
Every behaviour has a `node:test` test that is written and seen failing before the code that
makes it pass.

### II. No dependencies
The tool runs on Node 18+ with the standard library only. No `npm install` step.

### III. Docs move with the code
A change to behaviour or usage updates `README.md` in the same change.

## Governance
This constitution overrides other practice. Amendments are made by pull request and bump the
version.
